# Security Policy

## Supported versions

Security fixes are currently applied to the latest code on the default branch.

## Reporting a vulnerability

Please do **not** open public issues for security problems.

If GitHub private vulnerability reporting is enabled for this repository, use
that channel. Otherwise, contact the maintainer through a private channel and
request a secure handoff before sharing details.

When reporting a vulnerability, include:

- A short description of the issue
- The affected area or files
- Reproduction steps or a proof of concept
- The potential impact
- Any suggested mitigation, if you have one

You can expect an initial acknowledgement as soon as practical, followed by
triage and a plan for remediation or disclosure.

## Scope

Please focus reports on vulnerabilities in this repository's source,
configuration, or release artifacts. General support questions and product
feedback should go through the standard issue templates instead.
